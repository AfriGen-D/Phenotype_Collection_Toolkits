## Welcome

The Phenotype Collection Toolkits offer **standardised data collection protocols** for researchers in genomic and health research, particularly on the African continent. Each toolkit provides a REDCap project file, a data dictionary for other software platforms, annotated case report forms and a guideline. This means essential variables are collected the same way across research groups, which makes downstream data harmonisation much easier.

::: tip What's new
- **African Population Ontology** — the toolkits now include the [AfPO](https://github.com/h3abionet/afpo) lookup to record participants' population data.
- **French translations** — all toolkits are now fully available in French.
:::

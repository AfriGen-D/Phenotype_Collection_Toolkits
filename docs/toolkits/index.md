# The Toolkits

The suite contains **13 phenotype toolkits**. Each one provides data collection forms you can use to build a research database. Together they support phenotype standardisation and harmonisation across the African continent and the wider research community, and can form the basis of data models for post hoc harmonisation.

::: info Combining toolkits
Toolkits **00–10** can be used on their own or combined. The **Microbiome** and **COVID-19** toolkits are stand-alone only and can't be combined with the others.
:::

## General biomedical toolkits

| | Toolkit | Covers |
|---|---|---|
| 00 | [Core Phenotype Toolkit](./core) | Demographics, anthropometrics, tobacco and alcohol use, disease history |
| 01 | [General Medical History](./general-medical-history) | Allergies, pregnancy, surgery, and disorders across all body systems |
| 02 | [Cancer](./cancer) | Prognosis & treatment history, screenings, family history |
| 03 | [Stroke](./stroke) | Stroke characterisation, verification, primary & secondary prevention |
| 04 | [Infectious Diseases](./infectious-diseases) | Malaria, trypanosomiasis, tuberculosis, HIV |
| 05 | [Cardiovascular Diseases](./cardiovascular-diseases) | Anthropometrics, CVD history, blood flow, biomarkers |
| 06 | [Rare & Developmental Disorders](./rare-developmental-disorders) | Birth history, neurodevelopment, epilepsy, system anomalies |
| 07 | [Environmental Exposures](./environmental-exposures) | Socio-economic status, occupational history, water resources |
| 08 | [Lifestyle Factors](./lifestyle-factors) | Physical activity, diet, supplements, caffeine, sleep |
| 09 | [Family History](./family-history) | Family composition and medical history by body system |
| 10 | [Kidney Disease](./kidney-disease) | Kidney failure history, kidney function, blood cell count |

An **All-in-One Phenotype Toolkit** combining toolkits 00–10 in a single REDCap project is also available in the [GitHub repository](https://github.com/AfriGen-D/Phenotype_Collection_Toolkits/tree/main/All%20In%20One%20Phenotype%20Tookit%20v3.0).

## Specialised toolkits

| Toolkit | Covers |
|---|---|
| [Microbiome](./microbiome) | Participant, sample and sequencing metadata for human and environmental microbiome studies |
| [COVID-19](./covid-19) *(archived)* | Clinical and epidemiological data for SARS-CoV-2 and MIS-C |

## What's in each toolkit folder

- **Guideline** — how to administer each protocol (English & French)
- **REDCap XML file** — import to create a ready-built project
- **Annotated PDF** — case report forms in English and French
- **Data dictionary** — variable metadata for REDCap or other platforms
- **Translation file** — French translations for REDCap Multi-Language Management

Not sure how to get started? Follow the [REDCap Implementation Guide](/guide/redcap-setup).

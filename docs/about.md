# About the Toolkits

The Phenotype Toolkits offer standardised data collection protocols for researchers in genomic and health research, particularly on the African continent. They let you quickly set up a clinical data collection database, using REDCap .xml files or data dictionaries for other software platforms. Essential variables are then collected in a standard way that matches other research groups using the toolkits. Each variable also carries international annotations, which makes downstream data harmonisation much more likely to succeed.

The benefits are threefold:

1. The toolkits are aligned with existing **global data collection standards**.
2. They are **specifically adapted** for biomedical phenotype data collection in Africa.
3. They are **highly interoperable**, with variables mapped to existing, maintained ontologies.

## Who can use the toolkits?

The toolkits are intended for any genomic and health research. Any researcher or clinician can use them to collect data from participants in a research study.

## Why use the toolkits?

The toolkits are a standardised set of data collection instruments designed for genomic and health research, so you can set up a research database quickly and easily.

Collaborating researchers who use them take a proactive step towards data harmonisation, through standardised, annotated metadata and a shared data schema. Projects that use the toolkits will find it much simpler to harmonise their datasets with other users', because they share the same data standards, collection guidelines, variable names and formatting. The international metadata annotations also support the FAIR data principles, especially interoperability.

## What's in each toolkit?

| Component | Purpose |
|---|---|
| **REDCap XML file** | Creates a new REDCap project with the toolkit built and ready to use |
| **Data dictionary** | Metadata for every variable; can be imported into REDCap or replicated in another platform |
| **Annotated PDF (English & French)** | Case report forms for paper-based data collection or reference |
| **Guideline** | How to administer each protocol |
| **Translation file** | French translations for REDCap's Multi-Language Management tool |

## Can I edit the toolkits?

Yes. You can remove variables or add new ones to match your study's objectives. Make changes carefully, though, so you keep the benefits of standardisation. Check that deletions or additions don't break the existing branching logic or remove essential data.

::: warning Please don't rename variables
We don't recommend changing existing variable names, because this breaks harmonisation with other studies. You're welcome to add your own annotations to variables.
:::

If you use the translations, any changes will also need the translated elements to be reviewed and approved in REDCap's Multi-Language Management (MLM) tool.

See [Adapting toolkit instruments](/guide/redcap-setup#_7-adapting-instruments-for-your-study) in the REDCap guide for step-by-step instructions.

## History

The Human Heredity and Health in Africa (H3Africa) consortium was set up to drive new and innovative genomics research in Africa and to build capacity on the continent. As part of the consortium, the H3Africa Bioinformatics Network (H3ABioNet) was formed to support these efforts. It focused particularly on producing and sharing FAIR (Findable, Accessible, Interoperable and Reusable) data.

To standardise phenotypic data and share it between studies, within H3Africa and across consortia, a **Phenotype Harmonisation Working Group** was established. The group defined a core set of commonly collected phenotypes and associated data collection protocols, so that diverse studies could collect harmonised phenotypic data.

Development started with a **Core Phenotype Toolkit**, which draws on and aligns with the [PhenX Toolkit](https://www.phenxtoolkit.org/) to promote interoperability. The work then expanded into domain- and disease-specific toolkits. These were built through consensus mapping across H3Africa projects, by identifying shared phenotypes, and by selecting, adapting or developing protocols suitable for African research settings.

All toolkits were reviewed by African domain specialists, annotated with international ontologies and given clear data collection guidelines. This makes them robust, relevant to their context and useful for harmonised research within H3Africa and beyond.

From 2024, the toolkits have been maintained and developed by [AfriGen-D](https://afrigen-d.org), the African Genomics Data Hub.

**Publication:** Zass L, Johnston K, *et al.* [Developing Clinical Phenotype Data Collection Standards for Research in Africa](https://doi.org/10.1155/2023/6693323). 2023.
